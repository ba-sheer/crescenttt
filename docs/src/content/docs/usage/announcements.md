Open **Announcements** from the sidebar to read posts from the Crescent team. Announcements are public, but like other views they are loaded using your API key.

## What each entry shows

- **Author** and **posted time**
- **Title**, if the announcement has one
- A **text preview**. If the API marked the text as truncated, it ends with `[...]`
- The announcement **URL**, shown when the entry is selected

Use `↑` / `↓` to move between entries and `r` to refresh. If nothing has been posted, the view says "No announcements."

:::tip
The preview can be cut off. Copy the URL of a selected entry to read the full announcement in your browser.
:::

:::caution
The announcements view draws as many entries as fit on screen and does not scroll. If you have a short terminal, enlarge it to see more.
:::
